# running

## 주법

- 힐풋 으로 들어와서 프론트 풋으로 치고 나간다.
- 미드풋이 먼저 바닥에 닫는 주법은 몸에 부담이 매우 크다.
- 발의 앞 방이 몽의 진행방향을 향하도록 한다.(8자 보법 위험)

## 호흡법

- 코와 입으로 같이 숨쉰다. 동시에 마시고 동시에 내밷는다.
- 깊게 들이마쉬고 빨리 뱉는다. (쑥 마시고 후욱 내뱉고, 습 하아-)

## 초보

무리하지 말고 뛸수 있을만큼 뛰고 걸어라. 다시 뛸수 있게 되면 뛰고 반복.
본인의 능력에 맞게 500m 걷고 500m 뛰고, 1k 걷고 1k 뛰고...
거리는 중요하지 않으며 부상없이 꾸준히 러닝을 반복하는 것이 중요

몸이 땀에 젖기 전에는 페이스를 올리지 말고 천천히 뛰어라.
목덜미가 완전히 젖으면 페이스를 올려라.
